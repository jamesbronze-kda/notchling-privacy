# Notchling Privacy

Site público da Política de Privacidade do Notchling, publicado pelo GitHub
Pages para uso no App Store Connect e no TestFlight interno.

- URL pública: <https://jamesbronze-kda.github.io/notchling-privacy/>
- idioma: Português (Brasil)
- versão coberta: `0.5.0 (5)`
- contato: `gilberto.sirq@gmail.com`

O texto-fonte auditável também é mantido no repositório principal do app em
`docs/release/PRIVACY_POLICY_PT_BR.md`.

Publicação existente: GitHub Pages, branch `main`, pasta `/`, HTTPS habilitado.
A política descreve Apple opcional, exclusão no app e limites de remoção de
logs/backups. Não afirma que todas as integrações estejam validadas.
